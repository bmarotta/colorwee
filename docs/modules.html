colorDistanceSquared

  • colorDistanceSquared(c1: Rgb, c2: Rgb, normalize?: boolean): number
    • Defined in color.ts:563

    Same as colorDistance, but returns the squared distance (skips the square root). Use it to compare against a threshold: colorDistanceSquared(c1, c2) <= threshold * threshold gives the same answer as colorDistance(c1, c2) <= threshold, except when the distance equals the threshold to floating-point precision

    Parameters

    • c1: Rgb

      The first color to compare

    • c2: Rgb

      The second color to compare

    • normalize: boolean = false

      When true returns a value between 0 and 1 (the square of the normalized distance)

    Returns number

    The squared distance between 2 colors
